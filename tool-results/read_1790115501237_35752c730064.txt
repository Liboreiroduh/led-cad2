     1→# TASK MASTER — LED JSON CAD BUILDER
     2→## Novo projeto do zero — CAD dirigido por JSON + IA como transformadora de documento
     3→
     4→**Agente alvo:** Fable 5.1 — Medium  
     5→**Modo:** implementação autônoma e contínua  
     6→**Nome recomendado do projeto:** `led-json-cad`  
     7→**Objetivo:** construir um CAD para estruturas de painéis LED cuja fonte de verdade seja um documento JSON completo. A IA não opera o CAD por comandos; ela lê o JSON atual, entende o pedido do usuário e devolve um novo JSON completo e válido. O sistema valida, calcula diff, renderiza preview e só aplica após confirmação.

    32→# 1. VISÃO DO PRODUTO
    33→
    34→O produto é um CAD de estruturas LED orientado a documento.
    35→
    36→Fluxo principal:
    37→
    38→```text
    39→TEXTO / PRESET / IMAGEM / PDF / JSON
    40→                ↓
    41→            IA interpreta
    42→                ↓
    43→       PROJECT JSON candidato
    44→                ↓
    45→      Pydantic / validação geométrica
    46→                ↓
    47→      diff JSON atual × candidato
    48→                ↓
    49→            PREVIEW 3D
    50→                ↓
    51→         usuário APROVA
    52→                ↓
    53→    PROJECT JSON candidato vira atual
    54→                ↓
    55→       PDF / BOM / export JSON
    56→```
    57→
    58→Princípio central:
    59→
    60→```text
    61→JSON descreve o projeto.
    62→IA escreve ou reescreve o JSON.
    63→Python valida.
    64→Renderer desenha.
    65→Usuário aprova.
    66→```
    67→
    68→A IA NÃO deve devolver mini-operações como:
    69→
    70→```text
    71→add_post
    72→move_element
    73→delete_element
    74→resize_element
    75→multi_move
    76→```
    77→
    78→Esse contrato de operações foi um limitador no projeto anterior.
    79→
    80→A nova IA devolve o **documento completo desejado**.

    84→# 2. LIÇÃO PRINCIPAL DO PROJETO ANTIGO
    85→
    86→O projeto antigo provou que a IA frequentemente entende corretamente o pedido, mas falha porque o executor não aceita algum campo ou porque uma operação específica não existe.
    87→
    88→Exemplo do problema antigo:
    89→
    90→```text
    91→IA entendeu "adicione um poste"
    92→→ devolveu add_post com group
    93→→ schema de add_post não aceitava group
    94→→ pedido falhou mesmo com intenção correta
    95→```
    96→
    97→No projeto novo isso NÃO deve existir.
    98→
    99→Se a IA quer um poste, ela simplesmente devolve no JSON:
   100→
   101→```json
   102→{
   103→  "id": "POST-02",
   104→  "type": "beam",
   105→  "role": "post",
   106→  "profile": "TUBO_219x4.75",
   107→  "group": "POSTES",
   108→  "start": {"x": 500, "y": -325, "z": 0},
   109→  "end": {"x": 500, "y": -325, "z": 3000}
   110→}
   111→```
   112→
   113→O sistema valida e renderiza.

   117→# 3. O QUE MANTER DO PROJETO ANTIGO
   118→
   119→Conservar como conceitos:
   120→
   121→- unidade interna única: milímetros;
   122→- X = largura;
   123→- Y = profundidade;

   134→- PDF LED Collor dinâmico;
   135→- BOM derivado da geometria;
   136→- preview antes de aplicar;
   137→- undo atômico.
   138→
   139→Não portar:
   140→
   141→- Next.js;
   142→- dois servidores;
   143→- `ai_intent`;
   144→- `ai_contract` baseado em operações;
   145→- `ai_ops`;

   147→- `global_resize`;

   558→
   559→A IA não executa ferramentas CAD.
   560→
   561→Ela funciona como:
   562→
   563→```text
   564→Project JSON atual
   565→+ pedido do usuário
   566→+ schema
   567→+ regras
   568→        ↓
   569→      modelo
   570→        ↓
   571→Project JSON candidato completo
   572→```
   573→
   574→Contrato de retorno:
   575→
   576→```json
   577→{
   578→  "status": "ready",
   579→  "explain": "resumo curto do que foi alterado",
   580→  "assumptions": [
   581→    "mantive a gaiola a 3000 mm do solo"
   582→  ],
   583→  "questions": [],
   584→  "project": {
   585→    "...": "ProjectDocument completo"
   586→  }
   587→}
   588→```
   589→
   590→Quando faltar dado essencial:
   591→
   592→```json
   593→{
   594→  "status": "needs_input",
   595→  "explain": "faltam medidas essenciais",
   596→  "assumptions": [],
   597→  "questions": [
   598→    "Qual deve ser o pé-direito?"
   599→  ],
   600→  "project": null
   601→}
   602→```
   603→
   604→Máximo 3 perguntas.
   605→
   606→Não pedir respostas sobre coisas que podem ser preservadas do JSON atual.
