     1→     1→# TASK MASTER — LED JSON CAD BUILDER
     2→     2→## Novo projeto do zero — CAD dirigido por JSON + IA como transformadora de documento
     3→     3→
     4→     4→**Agente alvo:** Fable 5.1 — Medium  
     5→     5→**Modo:** implementação autônoma e contínua  
     6→     6→**Nome recomendado do projeto:** `led-json-cad`  
     7→     7→**Objetivo:** construir um CAD para estruturas de painéis LED cuja fonte de verdade seja um documento JSON completo. A IA não opera o CAD por comandos; ela lê o JSON atual, entende o pedido do usuário e devolve um novo JSON completo e válido. O sistema valida, calcula diff, renderiza preview e só aplica após confirmação.

    32→    32→# 1. VISÃO DO PRODUTO
    33→    33→
    34→    34→O produto é um CAD de estruturas LED orientado a documento.
    35→    35→
    36→    36→Fluxo principal:
    37→    37→
    38→    38→```text
    39→    39→TEXTO / PRESET / IMAGEM / PDF / JSON
    40→    40→                ↓
    41→    41→            IA interpreta
    42→    42→                ↓
    43→    43→       PROJECT JSON candidato
    44→    44→                ↓
    45→    45→      Pydantic / validação geométrica
    46→    46→                ↓
    47→    47→      diff JSON atual × candidato
    48→    48→                ↓
    49→    49→            PREVIEW 3D
    50→    50→                ↓
    51→    51→         usuário APROVA
    52→    52→                ↓
    53→    53→    PROJECT JSON candidato vira atual
    54→    54→                ↓
    55→    55→       PDF / BOM / export JSON
    56→    56→```
    57→    57→
    58→    58→Princípio central:
    59→    59→
    60→    60→```text
    61→    61→JSON descreve o projeto.
    62→    62→IA escreve ou reescreve o JSON.
    63→    63→Python valida.
    64→    64→Renderer desenha.
    65→    65→Usuário aprova.
    66→    66→```
    67→    67→
    68→    68→A IA NÃO deve devolver mini-operações como:
    69→    69→
    70→    70→```text
    71→    71→add_post
    72→    72→move_element
    73→    73→delete_element
    74→    74→resize_element
    75→    75→multi_move
    76→    76→```
    77→    77→
    78→    78→Esse contrato de operações foi um limitador no projeto anterior.
    79→    79→
    80→    80→A nova IA devolve o **documento completo desejado**.

    84→    84→# 2. LIÇÃO PRINCIPAL DO PROJETO ANTIGO
    85→    85→
    86→    86→O projeto antigo provou que a IA frequentemente entende corretamente o pedido, mas falha porque o executor não aceita algum campo ou porque uma operação específica não existe.
    87→    87→
    88→    88→Exemplo do problema antigo:
    89→    89→
    90→    90→```text
    91→    91→IA entendeu "adicione um poste"
    92→    92→→ devolveu add_post com group
    93→    93→→ schema de add_post não aceitava group
    94→    94→→ pedido falhou mesmo com intenção correta
    95→    95→```
    96→    96→
    97→    97→No projeto novo isso NÃO deve existir.
    98→    98→
    99→    99→Se a IA quer um poste, ela simplesmente devolve no JSON:
   100→   100→
   101→   101→```json
   102→   102→{
   103→   103→  "id": "POST-02",
   104→   104→  "type": "beam",
   105→   105→  "role": "post",
   106→   106→  "profile": "TUBO_219x4.75",
   107→   107→  "group": "POSTES",
   108→   108→  "start": {"x": 500, "y": -325, "z": 0},
   109→   109→  "end": {"x": 500, "y": -325, "z": 3000}
   110→   110→}
   111→   111→```
   112→   112→
   113→   113→O sistema valida e renderiza.

   266→   266→# 5. PROJECT JSON É A AUTORIDADE
   267→   267→
   268→   268→Criar um único modelo Pydantic principal:
   269→   269→
   270→   270→```python
   271→   271→ProjectDocument
   272→   272→```

   275→   275→
   276→   276→Formato base:
   277→   277→
   278→   278→```json
   279→   279→{
   280→   280→  "schema_version": 1,
   281→   281→  "units": "mm",
   282→   282→  "project": {
   283→   283→    "id": "uuid-ou-hash",
   284→   284→    "name": "Painel LED",
   285→   285→    "description": ""
   286→   286→  },
   287→   287→  "panel": {
   288→   288→    "width": 1920,
   289→   289→    "height": 960,
   290→   290→    "depth": 650,
   291→   291→    "ground_clearance": 3000
   292→   292→  },
   293→   293→  "installation": {
   294→   294→    "type": "post",
   295→   295→    "environment": "outdoor"
   296→   296→  },

   298→   298→  "assumptions": [],
   299→   299→  "metadata": {

   306→   306→O JSON atual é a fonte de verdade.
